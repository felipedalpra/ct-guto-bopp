# CT Guto Bopp

Site do **CT Guto Bopp** — Centro de Treinamento de Beach Tennis (Porto Alegre/RS).

Repositório privado: contém material do cliente (briefing, fichas e fotos dos professores).

## Estado atual

Fase de planejamento — **nenhum código foi criado ainda**. Stack definida:
Next.js (App Router) + TypeScript + Tailwind CSS, com deploy na Vercel.
